## 🆘 Need Help?

### Quick Troubleshooting

**Build fails?**
```bash
cd frontend
npm install
npm run build
```

**Pages 404?**
- Check Vercel dashboard
- Verify deployment completed
- May need to trigger rebuild

**No jobs showing?**
```bash
cd python-bridge
./start-bridge.sh
node scrape-all-jobs.js
```

**Schema errors?**
- Test at https://search.google.com/test/rich-results
- Check date formats (must be YYYY-MM-DD)
- Review `frontend/utils/schemaGenerator.ts`
