## 🆘 Need Help?

### Common Issues

**Pages showing 404?**
- Wait 3-5 minutes for Vercel cache to clear
- Clear your browser cache
- Check Vercel dashboard: https://vercel.com/dashboard

**No jobs showing on pages?**
- Run the scraper (see Step 3 above)
- Check MongoDB connection
- Verify API is responding

**Schema errors in Google Rich Results Test?**
- Check date formats (must be ISO 8601: YYYY-MM-DD)
- Verify all required fields present
- Review `frontend/utils/schemaGenerator.ts`
